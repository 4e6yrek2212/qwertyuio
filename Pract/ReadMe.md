# документация

### Обзор проекта
CoffeeERP - это простая система управления заказами для кофейни, реализованная на Python с использованием SQLite в качестве базы данных.

### Функционал

* Добавление данных в таблицу с заказами
* Удаление данных из таблицы
* Вывод данных в терминал(консоль)

``import sqlite3`` нужен для импорта таблицы sql в питон и дальнейшее её использование

``main.py`` - файл со всеми командами.

``tables.db`` - таблица с данными.
